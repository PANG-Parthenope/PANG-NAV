# Before publishing on GitHub

- [ ] Obtain confirmation of rights and redistribution authorization from relevant copyright holders.
- [ ] Audit third-party MATLAB routines and the redistribution terms for bundled RINEX datasets.
- [ ] Once authorized, add a correctly attributed BSD-3-Clause `LICENSE` file.
- [ ] Run PANG-NAV in MATLAB with the supplied RINEX examples and record MATLAB version/toolbox requirements.
- [ ] Verify GPS-only and GPS/Galileo runs, RAIM and optional error analysis.
- [ ] Confirm user manual accuracy and numerical outputs against the publication.
- [ ] Decide official first GitHub release number and attach ZIP.
- [ ] Publish GitHub repository and, if desired, archive a tagged release with Zenodo.
- [ ] Link repository, release and paper from panglab.eu/software/pang-nav/.
